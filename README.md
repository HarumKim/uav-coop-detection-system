# uav-coop-detection-system

Autonomous multi-drone system for fire detection, mapping, and inspection using computer vision and coordinated navigation.

---

## Project Overview

This project implements a **two-drone cooperative UAV system** designed to autonomously detect fires, map their locations, and perform close-range inspections.

The system is divided into two independent but coordinated missions:

- **Drone 1** scans the environment following a grid-based trajectory, detects fire using a custom YOLO model, and stores fire coordinates.
- **Drone 2** reads the detected coordinates, navigates to each fire location using geometric planning, visually aligns over the fire, and performs a low-altitude inspection.

The architecture emphasizes reliability, smooth flight control, and clear separation of responsibilities between drones.

## Drone 1 – Fire Detection and Mapping

**Objective:**  
Autonomously explore a rectangular grid, detect fires, and generate a fire map.

**Key Features:**
- Grid-based navigation using logical cell coordinates
- Visual alignment using white line detection
- YOLO-based fire detection with bounding boxes
- Multi-frame fire confirmation per cell
- Optimized motion timing to reduce unnecessary pauses
- Real-time visual feedback with OpenCV
- Automatic logging of detected fire coordinates

**Output:**
- `fire_coordinates.txt` containing detected fire locations as `(x, y)` grid coordinates

---

## Drone 2 – Fire Inspection and Verification

**Objective:**  
Navigate to detected fire locations and perform close-range inspection.

**Key Features:**
- Reads coordinates generated by Drone 1
- Always-forward navigation strategy (rotate + forward only)
- Euclidean path planning using `atan2`
- Yaw and distance correction for large-angle movements
- Local yaw sweep to search for fire if not immediately visible
- YOLO-based visual alignment over fire
- Controlled descent, hover, and ascent over fire
- Duplicate fire compaction and grid corner adjustment

## YOLO Fire Detection Model

- File: `best.pt`
- Framework: Ultralytics YOLO
- Trained specifically for fire detection
- Used by both drones:
  - Drone 1: fire detection and visualization
  - Drone 2: fire detection and visual servoing

**Detection Logic:**
- Any detection of the fire class is considered valid
- Confidence threshold affects visualization, not detection logic
- Multi-frame confirmation improves robustness

---

## Coordinate System

- Units: logical grid cells
- Origin `(0, 0)` at takeoff position
- Axes:
  - `+X`: forward direction
  - `+Y`: left direction
- Same coordinate system shared by both drones
- Physical scaling:
  - Drone 1: ~40 cm per cell
  - Drone 2: ~38 cm per cell (calibrated)

## connection_drones.py

This script orchestrates the complete mission:

1. Connects to Drone 1
2. Executes the fire detection and mapping mission
3. Safely lands Drone 1
4. Connects to Drone 2
5. Executes the fire inspection mission using detected coordinates

This design ensures clear mission separation and prevents mid-air interference.
